Polar Lights belohnt den Blick zum Himmel. Öffnen Sie auf dem Handy **Profil** → **Abzeichen**.

![Abzeichen: Ihr Rang, Ihre Punkte und Ihre erhaltenen Abzeichen](screen:badges)

## Punkte und Ränge

Sie erhalten Punkte für [bestätigte Sichtungen](/support/start/i-saw-it), für die Bestätigung der Meldung eines anderen Mitglieds sowie für Fotos und die „Hilfreich“-Stimmen, die sie bekommen. Mit Punkten steigen Sie im Rang auf:

| Rang | Punkte |
| --- | --- |
| Sterngucker | 0 |
| Wächter | 100 |
| Späher | 250 |
| Fährtenleser | 500 |
| Sturmjäger | 1.000 |
| Polarlichtjäger | 2.000 |
| Polarlegende | 4.000 |

Oben auf der Seite sehen Sie Ihren Rang und wie viele Punkte Ihnen bis zum nächsten fehlen.

## Abzeichen

Die Abzeichen sind in **Beobachter**, **Sturmzeuge**, **Mitwirkender**, **Entdecker** und **Erfahren** gruppiert. Viele haben Stufen, die Sie nacheinander erreichen. Tippen Sie auf ein Abzeichen, um zu sehen, wofür es steht und wann Sie es erhalten haben.

Manche Abzeichen bleiben geheim, bis Sie sie erhalten, und unter **Besondere Ereignisse** finden Sie Abzeichen für bestimmte Stürme und Anlässe.

> Abzeichen erscheinen etwa eine Stunde nach einer Meldung, sobald sie bestätigt ist. Siehe [Wann erscheinen meine Abzeichen und Punkte?](/support/faq/when-do-badges-appear)

## Abzeichen-Code einlösen

Wenn Sie einen Abzeichen-Code erhalten haben, tippen Sie unter **Haben Sie einen Abzeichen-Code?** auf **Einlösen**, geben Sie den Code ein und tippen Sie dann auf **Einlösen**. Manche Codes gelten nur für Chaser-Mitglieder.

![Code einlösen](screen:badges-redeem)

## Ihr Name in der Galerie

Ihr Rang und Ihre Abzeichen werden zusammen mit Ihrem **Name in der Galerie** angezeigt. Tippen Sie auf der Seite Abzeichen daneben auf **Ändern**, um einen anderen zu wählen.
