## Die Zeile Push prüfen

Öffnen Sie **Alarme** und sehen Sie sich unter **Zustellung per** die Zeile **Push** an. Der Text darunter zeigt, woran es liegt:

| Was dort steht | Was Sie tun können |
| --- | --- |
| **Auf diesem Gerät aktiv** | Push funktioniert hier. Prüfen Sie die weiteren Punkte unten. |
| Benachrichtigungen auf dem Handy, mit dem Hinweis **Chaser** | Push ist Teil von Chaser. Siehe [Tarife: Kostenlos und Chaser](/support/start/plans-and-chaser). |
| **Fügen Sie Polar Lights zuerst zum Home-Bildschirm hinzu** | Auf dem iPhone oder iPad funktioniert Push nur über den Home-Bildschirm. Siehe [Polar Lights auf Handy oder Computer nutzen](/support/start/install-polar-lights). |
| **Blockiert: Mitteilungen in den Android-Einstellungen › Apps › Polar Lights erlauben** | Benachrichtigungen sind für die Android-App ausgeschaltet. Schalten Sie sie dort ein und schalten Sie dann **Push** erneut ein. |
| **In den Browsereinstellungen blockiert** | Erlauben Sie in den Website-Einstellungen Ihres Browsers Benachrichtigungen für polarlights.io und schalten Sie dann **Push** erneut ein. |
| **In diesem Browser nicht verfügbar** | Verwenden Sie einen anderen Browser oder die Android-App. |
| **Bald in der Android-App** | Diese Version der App ist älter als die Push-Alarme. Aktualisieren Sie Polar Lights über Google Play. |

## Auf jedem Gerät einschalten

Push wird pro Gerät eingestellt. Wenn Sie es auf dem Handy einschalten, ist es dadurch nicht auf dem Computer eingeschaltet, und umgekehrt. Wenn Sie die App neu installieren oder die Browserdaten löschen, schalten Sie es erneut ein.

## Android: Energiesparen

Manche Android-Handys halten Benachrichtigungen von Apps zurück, die Sie ihrer Einschätzung nach nicht nutzen. Wählen Sie unter **Einstellungen** → **Apps** → **Polar Lights** → **Akku** die Option **Uneingeschränkt** (die Bezeichnung unterscheidet sich je nach Hersteller). Prüfen Sie außerdem, dass „Bitte nicht stören“ nachts nicht eingeschaltet ist.

## Immer noch nichts

Wenn **Letzte Alarme** auf der Seite Alarme Alarme auflistet, die nie als Benachrichtigung angekommen sind, schalten Sie **Push** auf diesem Gerät aus und wieder ein. Wenn das nicht hilft, wenden Sie sich an uns (siehe [Support kontaktieren](/support/troubleshooting/contact-support)). Zu Alarmen, die gar nicht gesendet wurden, siehe [Ich habe keinen Polarlicht-Alarm erhalten](/support/troubleshooting/no-aurora-alert).
