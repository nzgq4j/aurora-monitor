## Vérifier la ligne Push

Ouvrez **Alertes** et regardez la ligne **Push** sous **Envoyer par**. La mention en dessous indique ce qui ne va pas :

| Ce qui est indiqué | Que faire |
| --- | --- |
| **Activées sur cet appareil** | Le push fonctionne sur cet appareil. Vérifiez les autres points ci-dessous. |
| Notifications sur le téléphone, avec une étiquette **Chaser** | Le push fait partie de Chaser. Consultez [Offres : Gratuit et Chaser](/support/start/plans-and-chaser). |
| **Ajoutez d’abord Polar Lights à votre écran d’accueil** | Sur un iPhone ou un iPad, le push ne fonctionne que depuis l’écran d’accueil. Consultez [Installer Polar Lights sur votre téléphone ou votre ordinateur](/support/start/install-polar-lights). |
| **Bloquées : autorisez les notifications dans Paramètres Android › Applications › Polar Lights** | Les notifications sont désactivées pour l’app Android. Activez-les à cet endroit, puis réactivez **Push**. |
| **Bloquées dans les réglages du navigateur** | Autorisez les notifications pour polarlights.io dans les paramètres de site de votre navigateur, puis réactivez **Push**. |
| **Non pris en charge par ce navigateur** | Utilisez un autre navigateur, ou l’app Android. |
| **Bientôt dans l’app Android** | Cette version de l’app est antérieure aux alertes push. Mettez Polar Lights à jour depuis Google Play. |

## L’activer sur chaque appareil

Le push se règle appareil par appareil. L’activer sur votre téléphone ne l’active pas sur votre ordinateur, et inversement. Si vous réinstallez l’app ou effacez les données du navigateur, activez-le à nouveau.

## Android : économie de batterie

Certains téléphones Android retiennent les notifications des apps qu’ils pensent inutilisées. Dans **Paramètres** → **Applications** → **Polar Lights** → **Batterie**, choisissez **Sans restriction** (le libellé varie selon les fabricants). Vérifiez aussi que le mode Ne pas déranger n’est pas activé la nuit.

## Toujours rien

Si **Alertes récentes**, sur la page Alertes, liste des alertes qui ne sont jamais arrivées sous forme de notifications, désactivez puis réactivez **Push** sur cet appareil. Si cela ne suffit pas, [contactez l’assistance](/support/troubleshooting/contact-support). Pour les alertes qui n’ont jamais été envoyées, consultez [Je n’ai pas reçu d’alerte aurore](/support/troubleshooting/no-aurora-alert).
