## Ce que signifie le message

| Message | Que faire |
| --- | --- |
| **Cet e-mail et ce mot de passe ne correspondent à aucun compte.** | Vérifiez qu’il n’y a pas de faute de frappe dans l’adresse e-mail. Si vous avez oublié le mot de passe, réinitialisez-le (voir ci-dessous). Si vous avez créé le compte avec Google, touchez plutôt **Google**. |
| **Confirmez d’abord votre e-mail. Le lien se trouve dans votre boîte de réception.** | Ouvrez le lien de l’e-mail que nous vous avons envoyé lors de la création du compte. Vérifiez vos spams s’il n’est pas dans votre boîte de réception. |
| **Un compte existe déjà avec cet e-mail. Connectez-vous plutôt.** | Vous avez déjà un compte. Choisissez **Connexion**, ou réinitialisez le mot de passe. |
| **Trop de tentatives. Patientez quelques minutes et réessayez.** | Patientez quelques minutes avant de réessayer ou de demander un nouvel e-mail. |
| **Impossible de joindre le service de compte pour le moment.** | Vérifiez votre connexion et réessayez. |
| **Aucun compte Google sur ce téléphone.** | Dans l’app Android, la connexion avec Google utilise les comptes de votre téléphone. Ajoutez le vôtre dans **Paramètres** Android → **Mots de passe et comptes**, ou connectez-vous avec votre e-mail. |

## Réinitialiser votre mot de passe

1. Choisissez **Connexion**, puis **Mot de passe oublié ?**
2. Saisissez votre adresse e-mail et touchez **Envoyer le lien**.
3. Ouvrez le lien reçu par e-mail et choisissez un nouveau mot de passe d’au moins 8 caractères.

Le même message s’affiche qu’un compte existe ou non pour cette adresse e-mail, afin que personne ne puisse utiliser le formulaire pour savoir qui a un compte. Si aucun e-mail n’arrive, vérifiez vos spams et assurez-vous d’avoir saisi l’adresse utilisée lors de l’inscription.

## Connecté, mais vos lieux ou votre offre ont disparu

Vous êtes peut-être connecté à un autre compte, par exemple un compte créé avec Google et un autre avec un mot de passe. Ouvrez **Profil** pour voir avec quelle adresse e-mail vous êtes connecté, déconnectez-vous et connectez-vous avec l’autre compte.
